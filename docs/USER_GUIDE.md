# Vector Siege — macOS Help

Tank combat — command your terrain

## How to play

Choose a landscape, display mode, and threat level. Defend your tank against armored enemies and airborne threats. Use the dashboard telemetry for rounds, shield, heading, and threat indicators.

## Keyboard and mouse controls

| Control | Action |
|---|---|
| Return / any key | Deploy, then start the next level at the level banner. |
| WASD or arrow keys | Drive and turn. |
| I/O/K/L | Independent tread controls for pivoting or driving. |
| Space | Fire the cannon. |
| Shift | Activate the temporary shield. |
| E | Deploy anti-drone chaff. |
| P | Pause or resume. |
| R | Restart. |
| Click battlefield | Restore keyboard focus if needed. |

## Scores, saves and settings

Save Game records a local snapshot when a game is running. Resume loads previously saved slots. Custom Game presets and selected difficulty remain independent of the launcher and are not uploaded.

## Application menus

The native **Game** menu offers How to Play, Controls & Shortcuts, and Scores & Saving. The **Help** menu opens these offline instructions. Standard macOS App, Edit, Window, and Quit commands remain provided by the operating system. In-game gameplay buttons and shortcuts are unchanged.
